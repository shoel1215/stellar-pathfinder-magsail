# Stellar PF-MagSail

**Defensive Publication**  
Persistent-Field Magnetic Sail system with orbital thermal regeneration, electrodynamic self-deployment, and reconfigurable superconducting geometry.

This repository constitutes a public defensive publication of the inventions described herein. All content is dedicated to the public domain under **CC0 1.0 Universal**.

## Core Inventions

### 1. Orbital Thermal Cycling Regenerator
Pulse-tube cryocooler integrated with phase-change material (PCM — DMSO/water) thermal battery. Regenerates cooling capacity indefinitely using LEO day/night thermal gradients. Enables persistent superconducting current without active recharge or expendable cryogen.

### 2. Electrodynamic Self-Deployment System
Deployment of superconducting MgB₂ coil using only its own Lorentz self-field forces + permanent-magnet snap-fit latches. Requires zero motors, hinges, or external fields.

### 3. Reconfigurable Superconducting Geometry
In-orbit real-time shape and topology control of the persistent-current coil (planar → conical → split) via sequenced segment energization. Supports thrust vectoring, torque cancellation, and optimized solar-wind interaction.

## Supporting Novel Technologies

- **Persistent-Field Magnetic Sail (PF-MagSail) Architecture** — CubeSat-to-km-scale superconducting MagSail that maintains multi-Tesla field indefinitely after a single charge.
- **Modular Segment-Based Orbital Assembly System** — Standardized 1 m MgB₂ segments with integrated cooler, diagnostics, and magnetic snap-fit joints designed for robotic kilometer-scale assembly.
- **Per-Segment Quench Protection & Isolation** — Bypass diodes, thermal fuses, and redundant paths allowing single-segment quench without cascade failure.
- **Magnetic Field Shaping for Crew Radiation Shielding** — Active topology control creating low-flux equatorial safe zones + passive water shielding.
- **Sequential Energization Assembly Protocol** — Step-by-step orbital charging and verification coordinated with assembly robots.
- **PF-3 Specialized Assembly Robot End Effectors** — Vision-guided cold-welding/crimping tools for superconducting joints in vacuum.
- **Pathfinder Thermal Module** — Commercial spin-off: standalone high-margin 30 K cryocooler + PCM regenerator for quantum computing, IR sensors, and laboratory use.
